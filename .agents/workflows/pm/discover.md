# /discover — PM Discovery Workflow
1. **Load opportunity-solution-tree skill (Layer 2)**.
2. **Step 1: Define desired outcome** (user input required) — must be measurable.
3. **Step 2: Research opportunities** — use /browse for market/user research if needed.
4. **Step 3: Map opportunities → solutions** (min 2 solutions per opportunity).
5. **Step 4: Prioritize assumptions using RICE framework** (Reach, Impact, Confidence, Effort).
6. **Step 5: Design experiments** (Given/When/Then format).
7. **Step 6: Select top-priority experiment** → feed into /opsx:propose.
8. **Step 7: Archive OST** to .agents/knowledge/context/<slug>-ost.md.
9. **Output**: ost-<date>.md in .agents/artifacts/.
