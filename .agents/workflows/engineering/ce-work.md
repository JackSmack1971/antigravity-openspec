# /ce-work — Execution & Implementation

## Purpose
The execution phase of the continuous loop: `/ce-brainstorm → /ce-plan → /ce-work → /ce-code-review → /ce-compound`.

## Preconditions
- Requires: `docs/plans/[active-plan].md` generated by `/ce-plan`.

## Execution
1. **Setup:** Utilize git worktrees (`/using-git-worktrees`) if necessary to isolate changes.
2. **Task Tracking:** Follow the generated plan iteratively. Use `task_plan.md` or a checklist to track progress.
3. **Implementation:** Write code, tests, and documentation. Adhere to the L0 Foundational Rules (e.g., Think Before Coding, Surgical Edits).
4. **Handoff:** Once implementation and local testing are complete, trigger `/ce-code-review` for multi-agent validation.
