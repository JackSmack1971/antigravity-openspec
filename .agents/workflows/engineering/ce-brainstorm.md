# /ce-brainstorm — Requirements Brainstorming

## Purpose
The first phase of the continuous execution loop: `/ce-brainstorm → /ce-plan → /ce-work → /ce-code-review → /ce-compound`.

## Preconditions
- Requires: `STRATEGY.md` (from `/ce-strategy`).

## Execution
1. **Context Ingestion:** Read `STRATEGY.md` to understand the target problem, approach, persona, and metrics.
2. **Ideation:** Brainstorm technical requirements, potential edge cases, and architectural approaches.
3. **Requirement Gathering:** Output a structured list of actionable requirements.
4. **Handoff:** Pass the requirements list directly to `/ce-plan` for multi-phase planning.
