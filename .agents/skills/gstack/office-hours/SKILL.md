# office-hours — Strategic CEO Diagnostic

## Purpose
This skill provides a high-level strategic review to ensure the agent is working on the most impactful task and hasn't lost sight of the core user problem.

## 5-Question Diagnostic
Before proceeding with any complex task, execute this diagnostic:
1. **The User Problem**: What is the actual problem the user is trying to solve, beyond the literal request?
2. **The Riskiest Assumption**: What is the one assumption that, if false, would cause the entire project to fail?
3. **The Simple Version**: What is the simplest possible version of this solution that provides 80% of the value?
4. **The 10x Vision**: What would a 10x better version of this solution look like?
5. **The Fearless Action**: What would you do if you knew it was impossible to fail?

## Output
- **Reframed Problem Statement**: A 1-2 sentence distillation of the core objective.
- **Highest-Leverage Action**: The single next step that provides the most clarity or value.
